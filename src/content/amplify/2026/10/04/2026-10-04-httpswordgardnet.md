<p><strong>Wordgard</strong> [wɜrd-gɑrd] noun A garden for cultivating words. Open-source JavaScript library implementing an in-browser rich-text editor.</p>
<p>Wordgard provides a set of tools for building content editors. It is not a free-form HTML editor, but one where you control precisely what kind of content you support.</p>
<p>Its main distinguishing feature is a powerful programming interface that makes the library a good foundation for customized editors—even complex, demanding ones.</p>
<h2>Features</h2>
<ul> <li><a href="https://wordgard.net/docs/ref/"> <p>Most editor features are implemented as extensions, which means you can replace or modify them when they don't work for you.</p> </a></li> <li> <p>Works for screen reader users, keyboard-only users, and mobile devices. Support for UI internationalization.</p> </li> <li><a href="https://wordgard.net/docs/ref/#state.GardState.textLTR"> <p>Direction-aware in both the content and the interface. Supports bidirectional content and right-to-left documents.</p> </a></li> </ul>
