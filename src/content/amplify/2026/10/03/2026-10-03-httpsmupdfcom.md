<div><article>
<p>
					MuPDF is a lightweight PDF, XPS, and E-book viewer.
					</p>
<p>
					MuPDF consists of a software library, command line tools, and viewers for various platforms.
					</p>
<p>
					The renderer in MuPDF is tailored for high quality anti-aliased graphics. It
					renders text with metrics and spacing accurate to within fractions of a pixel
					for the highest fidelity in reproducing the look of a printed page on screen.
					</p>
<p>
					The viewer is small, fast, yet complete.
					It supports many document formats, such as PDF, XPS, OpenXPS, CBZ, EPUB, and FictionBook 2.
					You can annotate PDF documents and fill out forms with the mobile viewers (this feature is
					coming soon to the desktop viewer as well).
					</p>
<p>
					The command line tools allow you to annotate, edit, and convert documents to
					other formats such as HTML, SVG, PDF, and CBZ.
					You can also write scripts to manipulate documents using Javascript.
					</p>
<p>
					The library is written modularly in portable C, so features can be added and removed by integrators if they so desire.
					We also have a Java library using JNI that works on both Oracle's Java and Android.
					</p>
<p>
					Go to the <a href="https://artifex.com/products-mupdf-overview/" target="_blank">Artifex MuPDF product overview</a> to learn more.
					</p>
