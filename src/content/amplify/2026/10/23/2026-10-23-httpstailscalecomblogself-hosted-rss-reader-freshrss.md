title: It's time to make your own RSS reader
---
<div><div><p>It may not feel like it, but there is still a way to read things online that humans have written, chosen and sorted by you,<a href="https://www.eff.org/deeplinks/2026/06/hate-algorithm-rss-one-tools-youve-been-looking" rel="noreferrer" target=""> not an algorithm</a>. That way is RSS (Really Simple Syndication). You can self-host one for free, and you can use Tailscale to set up one reader you access everywhere.</p><p>Why would you tackle this almost retro-feeling project? Maybe you’d like a bit less doom in your scrolling. Perhaps you’re sick of attention-optimized designs, barely differentiated sponsored content, or seeing the same "news" suggested to you 12 different times. Or, this being 2026, you might want to feed an AI agent a focused feed so it can pick out highlights.</p><p>This post will walk through setting up<a href="https://www.freshrss.org/" rel="noreferrer" target=""> FreshRSS</a>, which works as both an RSS aggregator (the hub that fetches feeds) and a reader (shows you feeds’ content). It’s one of the easiest things to self-host, whether or not you have hardware for it at home. And we’re giving FreshRSS its own secure URL through Tailscale, so nothing is exposed on the open web, but you can reach it easily.</p><p>RSS is the non-algorithmic fix: you choose what sites to follow (and sometimes individual topics or authors), and then you get their posts. Use RSS a few times to get your awareness hits, and it’s hard to go back to anything else. It has an indie feel to it, because this kind of personalized, information-dense style of reading was never going to be the default. Which is fine and, frankly, it rocks.</p><p>Before any of this setup,<a href="https://start.tailscale.com/login" rel="noreferrer" target=""> you need a Tailscale account</a>. The Personal plan is free, gives you unlimited devices and multiple users, so you’re well covered for this little news-reading project.</p><figure><img _type="asset" alt="RSS hub aggregation flowchart illustrating how multiple news sources and content feeds (actual news sites, release notes, and blog comments) are consolidated through an RSS feed hub with filtering capabilities to deliver personalized content to users like Alice." data-nimg="1" decoding="async" height="2160" loading="lazy" src="https://cdn.sanity.io/images/w77i7m8x/production/f37d5fe91e8cb531245aa415c8c8f8a2c21be645-3840x2160.png?w=3840&amp;q=75&amp;fit=clip&amp;auto=format" video="[object Object]" width="3840"/></figure><p>We’re doing this with Docker because<a href="https://freshrss.github.io/FreshRSS/en/admins/03_Installation.html" rel="noreferrer" target=""> Docker is what the FreshRSS makers want you to use</a>. If you’ve never set up a Docker container before, it can sound like a lot. But we’re starting small, with a setup file that bakes Tailscale right into it. Using Docker, the install instructions for FreshRSS will be quite similar for everybody, whether deploying on a virtual private server (VPS), an old laptop, a Raspberry Pi, or a Mac mini.</p><p>Here’s the least painful way forward.</p><ol><li>Grab the desktop app on Windows or Mac. If your always-on machine runs Windows or macOS, grab the<a href="https://www.docker.com/products/docker-desktop/" rel="noreferrer" target=""> Docker desktop app</a> for that system. Install the app, launch it, and keep following along.</li><li>Open a terminal. On a Linux system that doesn’t have a desktop (like a VPS), you’re already at a terminal (a "shell," technically). If you’re on Windows, launch <a href="https://apps.microsoft.com/detail/9n0dx20hk701?hl=en-US&amp;gl=US" rel="noreferrer" target="">Terminal</a> (or PowerShell, they both work), and on macOS, just Terminal. On Raspberry Pi OS, or another Linux system with a desktop, look for a terminal or "term" app and open it.</li><li>See if you’ve already got a recent Docker install. Type this into your terminal and hit Enter: <code>docker compose version</code>. If it returns any version, then you’re good to keep moving. If not, enter this script, which will install and update Docker on nearly every major Linux system: <code>curl -fsSL https://get.docker.com | sh</code>. Log out of your Linux system, then log back in, and now you can use Docker without typing <code>sudo</code> before important commands.</li><li>Fix your permissions: If you didn’t run Docker’s script, enter this command in your terminal to allow for performing key Docker functions: <code>sudo usermod -aG docker $USER</code> (noting the upper-case G). Then log out and log back in, or run <code>newgrp docker</code> to set yourself in the right group.</li><li>Test everything’s working: Enter <code>docker run hello-world</code> in your terminal to pull a test image.</li></ol><p>We’ve covered setting up Docker, and spinning up containers, in<a href="https://www.youtube.com/watch?v=YTjYXii4WzI" rel="noreferrer" target=""> a YouTube guide to getting started with Docker and Tailscale</a>. Alex’s video examples may be helpful, if anything in this blog guide isn’t quite clicking.</p><h2></h2><p>Make a directory on your device (or VPS) where you’re going to keep Docker containers, such as FreshRSS setup. It’s a good idea to plan for future projects, and an even better idea to put it in your home directory. On Linux and macOS (and a VPS with SSH access), that looks like this:</p><p>The <code>~</code> there is a shortcut for your home directory, so that’s actually <code>/home/username/docker</code>, swapping <code>username</code> for what you use. On Windows, in PowerShell, it’s <code>mkdir $HOME\docker</code>.</p><p><a href="https://github.com/tailscale-dev/ScaleTail/" rel="noreferrer" target="">ScaleTail</a> is a repository full of containers all set up to launch and add themselves to your Tailscale network (tailnet). I’ve<a href="https://github.com/tailscale-dev/ScaleTail/tree/main/services/freshrss" rel="noreferrer" target=""> added FreshRSS to the ScaleTail repository</a>. You’re going to download this directory, make a couple changes to a configuration file, and launch the container.</p><p>If you’re on macOS or Linux, you can, using the <code>git</code> command, clone the whole ScaleTail repository (it’s tiny), then head into the FreshRSS section to work with it:</p><div><pre><code>cd ~/docker
git clone https://github.com/tailscale-dev/ScaleTail.git
cd ScaleTail/services/freshrss</code></pre></div><p>Some macOS users will be prompted to install the "Xcode Command Line Tools." Do so; you’re obviously a developer now.</p><p>If you’re on Windows and the <code>git</code> command failed, I’d suggeste not installing Git into the PowerShell window; it’s more trouble than it’s worth. Instead, download<a href="https://github.com/tailscale-dev/ScaleTail/archive/refs/heads/main.zip" rel="noreferrer" target=""> a ZIP file of the ScaleTail repository</a>. Move the ZIP file into that <code>docker</code> folder you made in your home directory. Unzip the file there, and it should create a directory, <code>ScaleTail-main</code>. From there, you can head into <code>ScaleTail-main/services/freshrss</code>. (For the rest of this post, whenever the directory <code>ScaleTail</code> is used, use <code>ScaleTail-main</code> instead).</p><p>Now let’s set this package up to connect through Tailscale.</p><h2></h2><p>If you haven’t already,<a href="https://start.tailscale.com/login" rel="noreferrer" target=""> create a Tailscale account</a>, and<a href="https://tailscale.com/download" rel="noreferrer" target=""> install it on the device with the Docker setup</a>. Once Tailscale is running on that device, you can access it from any other device on the tailnet. That makes it a lot easier to get back into this machine for troubleshooting, particularly if it’s a device without a screen and keyboard attached. You can<a href="https://tailscale.com/blog/tailscale-ssh" rel="noreferrer" target=""> later set up Tailscale SSH for even easier access</a>.</p><p>On Tailscale’s web admin console, head to<a href="https://console.tailscale.com/admin/settings/keys" rel="noreferrer" target=""> Settings &gt; Keys</a>. Click the Generate Auth Key button. Give the key a name, like <code>freshrss</code>. If you see a "Pre-approved" option, toggle it on.</p><p>Click Generate key, and copy the key—don’t close the window while you do this next part.</p><p>Inside your <code>~/docker/ScaleTail/services/freshrss</code> directory, there is a file, <code>.env</code>, where we need to add our key value. If you have a preferred text editor, open up the <code>.env</code> file with that. Otherwise, on macOS and Linux, you can run this command:</p><div><pre><code>nano ~/docker/ScaleTail/services/freshrss/.env</code></pre></div><p>That will open up the <code>.env</code> file in a very minimal, terminal-based editor, <code>nano</code>. Use the arrow keys to get to the line <code>TS_AUTHKEY=</code>, then put the cursor right after the <code>=</code> bit. To paste it, use Command+V on Mac, or Control+Shift+V on Linux. The line should read <code>TS_AUTHKEY=ts-abcxyz …</code>.</p><figure><img _type="asset" alt="Environment configuration file (.env) for UW PICO 5.09 displaying FreshRSS service setup with network, Tailscale, timezone, and admin credential settings in dark terminal interface." data-nimg="1" decoding="async" height="1216" loading="lazy" src="https://cdn.sanity.io/images/w77i7m8x/production/497630a70acc8ed591c584a2c82ead004bab04c7-1592x1216.png?w=3840&amp;q=75&amp;fit=clip&amp;auto=format" video="[object Object]" width="1592"/></figure><p>Don’t close the file after you’ve pasted your key; there are a few more edits to make. On the line <code>TZ=</code>, you enter your time zone after the equals sign, <a href="https://en.wikipedia.org/wiki/List_of_tz_database_time_zones" rel="noreferrer" target="">using the “tz” format</a>, like <code>America/New_York</code>.</p><p>For <code>TAILNET_NAME=</code>, head to your <a href="https://console.tailscale.com/admin/dns" rel="noreferrer" target="">web admin console’s DNS settings</a> to see your Tailnet DNS name. If you haven’t already, you can click Rename tailnet to get something more memorable than the default jumble of letters and numbers. If this is your first container on Tailscale, it’s a good time to roll for a new semi-random name. Either way, paste in the part showing in your console, like <a href="http://velociraptor-noodlefish.ts.net" rel="noreferrer" target=""><code>velociraptor-noodlefish.ts.net</code></a>.</p><p>Next to <code>ADMIN_PASSWORD</code>, and also <code>ADMIN_API_PASSWORD</code>, enter something sensible. These secure access to your FreshRSS dashboard, and then external access to its feeds and data, respectively. Set <code>ADMIN_EMAIL</code> to, most likely, your own email.</p><p>Finally, if you want this to show up on your tailnet as something other than a node named <code>freshrss</code>, change its name on the <code>SERVICE=</code> line near the top of the <code>.env</code> file.</p><p>Once you’ve pasted the key, time zone, tailnet name, passwords, and email (whew!), enter these commands: Control+O ("Write out," or save), Enter (to confirm the file name), then Ctrl+X (exit).</p><p>On Windows, your best bet is using<a href="https://code.visualstudio.com/download" rel="noreferrer" target=""> Visual Studio Code</a> (VSCode). Install it for your system, then use it to open the <code>.env</code> file in your <code>docker\ScaleTail-main\services\freshrss</code> directory. Make all the edits noted above: auth key, time zone, tailnet name (optional), passwords, and email. Do a little check in the bottom-right corner of VSCode to ensure it reads <code>LF</code>; if it reads <code>CRLF</code>, change it to <code>LF</code> (“Linux file endings”; it’s weird), and then save the file.</p><p>Time to launch our hub. In a terminal, make sure you’re in the directory where you put that <code>.env</code> and <code>compose.yaml</code> file (<code>cd ~/docker/ScaleTail/services/freshrss</code> if you used our layout earlier). Once there, enter: <code>docker compose up -d</code>. This tells Docker to use your compose file to bring a container "up," or set it running; the <code>-d</code> is "detached," meaning it keeps running when you eventually close this terminal.</p><figure><img _type="asset" alt="Docker Compose terminal output displaying successful deployment of 20 services including freshrss and tailscale containers. The screenshot shows container health status, pulled Docker images, and network creation with startup times, indicating a fully operational Docker containerized application stack." data-nimg="1" decoding="async" height="380" loading="lazy" src="https://cdn.sanity.io/images/w77i7m8x/production/069e696dc2273f9a244af183e6408c5a0fac765f-1598x380.png?w=3840&amp;q=75&amp;fit=clip&amp;auto=format" video="[object Object]" width="1598"/></figure><p>You should see Docker pull images, create networks and volumes (virtual drives), and start each container. Did they work? You can check with <code>docker compose ps</code>, which shows the status of each container. The <code>tailscale-freshrss</code> should eventually be <code>healthy</code> and <code>app-freshrss</code> reports <code>running</code>. If not, try checking in with <code>docker compose logs tailscale</code>. If you see lines about a key or "auth" being expired or invalid, try creating a new Tailscale key, placing it in the <code>.env</code> file, and running <code>docker compose up -d</code> again.</p><p>Once FreshRSS is running and healthy, and Tailscale is installed and connected, open a browser and head to <code>http://&lt;device-name&gt;.&lt;tailnet-name&gt;.ts.net</code>. Substitute your device/key name (like <code>freshrss</code>) and your tailnet name, like <code>noodlefish-velociraptor</code> (found at the <a href="https://console.tailscale.com/admin/dns" rel="noreferrer" target="">admin console’s DNS settings</a>).</p><figure><img _type="asset" alt="FreshRSS interface showing 7 unread stories, received on October 16, 2026, from sources including Darkreading, The Verge, The New Stack, ComputerWorld, Ars Technica, and InfoQ. Messages cover topics about AI agents, Android updates, Surface Laptop Ultra, and AI agent behavior. Search bar and action buttons visible at top." data-nimg="1" decoding="async" height="1058" loading="lazy" src="https://cdn.sanity.io/images/w77i7m8x/production/662dec1847a76af0bff58896037d808b5a0c1b65-1852x1058.png?w=3840&amp;q=75&amp;fit=clip&amp;auto=format" video="[object Object]" width="1852"/><figcaption>Be sure to check inside Settings &gt; Configuration &gt; Display for your choice of themes. Pictured: Nord.</figcaption></figure><p>Load up FreshRSS in your browser, then log in with that username/password you set up in your <code>.env</code> file.</p><p>You’re in. You’ll need to gather up your feeds. Often, you can paste the base URL for a website into FreshRSS’ "Add a feed" box and it will automatically find the RSS.</p><p>If that’s not working, scroll to the bottom of sites you’re interested in, and at the bottom, you’ll often find links to RSS or Feeds. Sometimes they’re only on the blog or news sections of a site. The<a href="https://www.eff.org/deeplinks/2026/06/hate-algorithm-rss-one-tools-youve-been-looking" rel="noreferrer" target=""> EFF’s guide to RSS</a> has good tips on curating a list of feeds, including from social sites, YouTube, Reddit, Tumblr, and other spots.</p><h3></h3><p>Want to use FreshRSS with NetNewsWire or another reading app? Want to expose it to AI agents, so it can scan your feeds and alert you about the most relevant news? You’re a few clicks away.</p><p>In FreshRSS Settings, head to the Authentication section. Check the box for Allow API access and click Submit. Next, under Profile in Settings, scroll down a bit, and you should see that an API password was set (in your <code>.env</code> file). If not, set it here, then hit Submit.</p><p>Setting up this API allows you to hook up NetNewsWire, Reeder, FeedMe, and other apps to FreshRSS. In NetNewsWire, go to Settings &gt; Add Account, head to the Self-Hosted section, and choose FreshRSS. Give it your API URL, which is either your tailnet address (<code>https://freshrss.&lt;your-tailnet&gt;.ts.net/api/greader.php</code>) or local URL (<code>http://&lt;IP-address&gt;:8080/api/greader.php</code>). Then add your username, and your API password (<em>not</em> your web login password), and you’re off and reading.</p><p>Want to hook up Claude, ChatGPT, Hermes, or other LLMs to your feeds? It’s the same API URL, where your agent can POST your username and API password to get an auth token, then get to work.</p><h2></h2><p>I have an LLM reading my FreshRSS feeds and making a digest of the most relevant items in Tailscale’s tech sectors, twice a day. It catches interesting stuff and contextualizes it. But it’s even more effective at nudging me to head into the full feed list, to both catch all the stuff I <em>didn’t</em> expect to see, and catch up on more news and updates further afield.</p><p>The<a href="https://www.theverge.com/23778253/google-reader-death-2013-rss-social" rel="noreferrer" target=""> death of Google Reader</a>, a seminal moment for Internet writers, readers, and enthusiasts, was not the death of RSS. It might have marked a major shift in how distributed and open the web felt to most people; it should have served as<a href="https://www.techdirt.com/2022/06/03/the-internet-can-still-be-small-and-nice-but-its-on-all-of-us-to-make-that-work/" rel="noreferrer" target=""> a wake-up call</a>. If you want something better than whatever is targeted to your web habits, you have to do a bit of curation. You have to find and sort your own flavors of thoughtful takes and surprising rabbit holes into your feeds. It’s seed work that pays off over time.</p><p>Go forth and gather up some feeds, and keep them on your own network.</p></div></div>
