<p><strong>A SoundFont Synthesizer</strong></p>
<p><strong>FluidSynth</strong> is a real-time software synthesizer based on the SoundFont 2 specifications and has reached widespread distribution. FluidSynth itself does not have a graphical user interface, but due to its powerful API several applications utilize it and it has even found its way onto embedded systems and is used in some mobile apps.</p>
<h2>Features</h2>
<ul> <li>Cross platform support (Linux, macOS and Windows to name a few)</li> <li>SoundFont 2 support</li> <li>SoundFont 3 support (vorbis-compressed SF2)</li> <li>Realtime effect control using SoundFont 2.01 modulators</li> <li>Limited support for Downloadable Sounds (DLS) Level 1 &amp; 2</li> <li>Playback of MIDI files</li> <li>Shared library which can be used in other programs</li> <li>Built in command line shell</li> </ul>
<p>A detailed chart of supported MIDI messages can be found <a href="https://github.com/FluidSynth/fluidsynth/wiki/FluidFeatures">in the wiki</a>.</p>
