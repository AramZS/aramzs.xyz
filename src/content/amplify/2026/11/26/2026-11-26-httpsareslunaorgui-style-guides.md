<p>This is a collection of preserved UI style guides a.k.a. interface guidelines from various companies, starting from the early 1980s and continuing to today.</p>
<ul> <li> <h3> Amiga </h3> <p> (Commodore) <a href="https://en.wikipedia.org/wiki/Amiga">Amiga</a> was a multimedia personal computer particularly popular in the 1980s and 1990s in Europe. Its GUI was called Workbench. </p> </li><li> Amiga User Interface Style Guide<br/> <figure data-no="1"> <img data-no="1" src="https://aresluna.org/images/ui-style-guides/amiga/cover.avif"/> </figure> <figure data-no="2"><img data-no="2" src="https://aresluna.org/images/ui-style-guides/amiga/2.avif"/></figure> <figure data-no="3"><img data-no="3" src="https://aresluna.org/images/ui-style-guides/amiga/1.avif"/></figure> </li></ul>
<ul> <li> <h3> Android </h3> <p> <a href="https://en.wikipedia.org/wiki/Android_(operating_system)">Android</a> is a mobile operating system and a rival to iOS. The first style guide I could locate was in 2012. </p> </li><li> <figure data-no="6"><img data-no="6" src="https://aresluna.org/images/ui-style-guides/android-2012/8.avif"/></figure> <figure data-no="7"><img data-no="7" src="https://aresluna.org/images/ui-style-guides/android-2012/7.avif"/></figure> <figure data-no="8"><img data-no="8" src="https://aresluna.org/images/ui-style-guides/android-2012/3.avif"/></figure> </li><li> <figure data-no="14"><img data-no="14" src="https://aresluna.org/images/ui-style-guides/android-2015/1.avif"/></figure> <figure data-no="15"><img data-no="15" src="https://aresluna.org/images/ui-style-guides/android-2015/2.avif"/></figure> <figure data-no="16"><img data-no="16" src="https://aresluna.org/images/ui-style-guides/android-2015/5.avif"/></figure> </li></ul>
<ul> <li> <h3> BlackBerry </h3> <p> <a href="https://en.wikipedia.org/wiki/BlackBerry">BlackBerry</a> was a beleagured maker of mobile handsets. </p> </li><li> BlackBerry Wireless Handheld User Interface Style Guide<br/> </li></ul>
<ul> <li> <h3> CDE </h3> <p> <a href="https://en.wikipedia.org/wiki/Common_Desktop_Environment">Common Desktop Environment</a> (CDE) is a desktop environment for Unix machines, using (and eventually merging with) OSF/Motif widgets. </p> </li></ul>
<ul> <li> <h3> CUA </h3> <p> <a href="https://en.wikipedia.org/wiki/IBM_Common_User_Access">Common User Access</a> (CUA) is a late 1980s standard for user interfaces that influenced Windows and OS/2. </p> </li></ul>
<ul> <li> <h3> GEM/TOS </h3> <p> <a href="https://en.wikipedia.org/wiki/GEM_(desktop_environment)">Graphics Environment Manager</a> (GEM) is a 1980s operating system/GUI. It was well-known by users of the Atari ST computers, known in these circles as <a href="https://en.wikipedia.org/wiki/Atari_TOS">TOS</a>. </p> </li></ul>
<ul> <li> <h3> GNOME </h3> <p> <a href="https://en.wikipedia.org/wiki/GNOME">GNOME</a> is a desktop environment for Linux and BSD operating systems. Note that the versioning number of these guidelines is very confusing. </p> </li><li> GNOME Human Interface Guidelines<br/> </li></ul>
<ul> <li> <h3> iOS and iPadOS </h3> <p> iOS (previously iPhone OS) is Apple’s mobile operating system for iPhone smartphones and their siblings. </p> </li><li> iPhone Human Interface Guidelines<br/> Covers the skeuomorphic era of iOS 1–6<br/> </li><li>  Covers iOS 7+<br/> </li><li> iPad Human Interface Guidelines<br/> </li></ul>
<ul> <li> <h3> Java </h3> <p> Java is a programming language, which comes equipped with JFC (Java Foundation Classes) and Swing GUI components. </p> </li></ul>
<ul> <li> <h3> Macintosh </h3> <p> These are some historical Apple GUI style guides, starting with Lisa in the 1980, and continuing to the “classic” Mac OS, with a brief stop in the Apple II corner. </p> </li></ul>
<ul> <li> <h3> Mac </h3> <p> More modern Apple Mac style guides, covering Mac OS X/Aqua and beyond. </p> </li><li>  Covers early years of Aqua<br/> </li><li>  Covers the era between pure Aqua and Liquid Glass<br/> </li></ul>
<ul> <li> <h3> Magic Cap </h3> <p> An abandoned mobile operating system designed by <a href="https://en.wikipedia.org/wiki/General_Magic">General Magic</a>. </p> </li></ul>
<ul> <li> <h3> Microsoft Office </h3> <p> Guidelines specific to Microsoft Office, in particular covering the use of its <a href="https://en.wikipedia.org/wiki/Ribbon_(user_interface)">ribbon</a>. </p> </li></ul>
<ul> <li> <h3> NeXTSTEP </h3> <p> <a href="https://en.wikipedia.org/wiki/NeXTSTEP">NeXTSTEP</a> was NeXT’s influential operating system and graphical user interface. It eventually morphed into OpenStep on one side, and modern Mac OS X on another. </p> </li></ul>
<ul> <li> <h3> Newton </h3> <p> <a href="https://en.wikipedia.org/wiki/Apple_Newton">Apple Newton</a> was Apple’s PDA launched in 1993 and abandoned in 1998. </p> </li></ul>
<ul> <li> <h3> Nokia </h3> <p> <a href="https://en.wikipedia.org/wiki/Nokia">Nokia</a> released various style guides for its early smartphones, including its <a href="https://en.wikipedia.org/wiki/Symbian">Symbian</a> operating system. </p> </li><li> The User Interface of Nokia 9110 Communicator<br/> </li><li> Symbian3 UI Style Guide<br/> </li></ul>
<ul> <li> <h3> OPEN LOOK </h3> <p> <a href="https://en.wikipedia.org/wiki/OPEN_LOOK">OPEN LOOK</a> is a UNIX graphical user interface, started by Sun and AT&amp;T. </p> </li></ul>
<ul> <li> <h3> Palm OS </h3> <p> <a href="https://en.wikipedia.org/wiki/Palm_OS">Palm OS</a> was the original graphical operating system for Palm’s mobile devices. Eventually, the company moved toward <a href="https://aresluna.org/ui-style-guides/#webos">webOS</a>, covered elsewhere on this page. </p> </li></ul>
<ul> <li> <h3> PenPoint </h3> <p> <a href="https://en.wikipedia.org/wiki/PenPoint_OS">PenPoint</a> was an early tablet operating system developed by GO Corporation for its unsuccessful line of devices. </p> </li></ul>
<ul> <li> <h3> RISC OS </h3> <p> <a href="https://en.wikipedia.org/wiki/RISC_OS">RISC OS</a> is a British operating system and GUI, developed originally for Acorn computers, and continuing as a community project. </p> </li></ul>
<ul> <li> <h3> Samsung </h3> <p> Various Samsung style guides. </p> </li></ul>
<ul> <li> <h3>Silicon Graphics</h3> <p> Style guides for various UNIX-based operating system from <a href="https://en.wikipedia.org/wiki/Silicon_Graphics">SGI</a>, or Silicon Graphics Inc. Just like <a href="https://aresluna.org/ui-style-guides/#cde">CDE</a> above, these too use the Motif widgets. </p> </li><li> SGI Indigo Magic User Interface Guidelines<br/> </li></ul>
<ul> <li> <h3> Taligent </h3> <p> Taligent was a troubled software company, incorporated as an Apple/IBM partnership. One of its fruits was a CommonPoint application framework. </p> </li></ul>
<ul> <li> <h3> webOS </h3> <p> <a href="https://en.wikipedia.org/wiki/WebOS">webOS</a> was a successor to <a href="https://aresluna.org/ui-style-guides/#palm-os">Palm OS</a> that was eventually purchased by HP and later LG Electronics. Today, it is used on smart TVs, refrigerators, and projectors. </p> </li><li> HP Touchpad webOS Design Guidelines<br/> </li></ul>
<ul> <li> <h3> Windows </h3> <p> Does Microsoft Windows need an introduction? Note a little hole here around 1990, where Microsoft was preoccupied with <a href="https://aresluna.org/ui-style-guides/#cua">CUA framework</a> in partnership with IBM. </p> </li><li> <ul> <li><a href="https://aresluna.org/ui-style-guides/Windows/Microsoft Windows Software Development Kit Application Style Guide (1986, 1.03).pdf">1986 1.03 PDF</a> </li></ul> </li><li> The Windows Interface Guidelines for Software Design<br/> </li><li> User Experience – Official Guidelines for User Interface Developers and Designers<br/> </li><li> Windows 8–10 User Experience Guidelines<br/> </li></ul>
<ul> <li> <h3> Windows Phone </h3> <p> Style guides for failed mobile Windows efforts, starting with <a href="https://en.wikipedia.org/wiki/Windows_Mobile_6.0">Windows Mobile 6</a>, and continuing through Windows Phone 7. </p> </li><li> Designing Applications for Windows Mobile Powered Platforms<br/> </li></ul>
<p>That’s it! Please <a href="https://aresluna.org">let me know</a> if you have any thoughts and particularly if you have some style guides that are missing from the above list.</p>
<p>Some of the above mirrors were lightly cleaned up to make their consumption easier – stuff like pixellating images better, inlining images instead of linking to them, or fixing YouTube embeds.</p>
<p>You can also <a href="https://aresluna.org/ui-style-guides/ui-style-guides.zip">download all the above style guides in one archive</a>.</p>
