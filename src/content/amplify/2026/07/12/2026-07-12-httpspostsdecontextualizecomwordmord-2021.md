<p>Wordmord Workshop</p>
<p>We know computers best as tools for analyzing text, composing text, and “correcting” text through grammar and spell check. But computation is an equally useful tool for pulling language apart, grinding it down, and making it unfamiliar. This workshop offers a short series of hands-on tutorials with code that facilitates destructive and defamiliarizing operations on text. The workshop culminates in a collaboratively produced online zine. No previous programming experience is required.</p>
<p>We’re using Google Colab to run Python code. I’ll take you through how to use the notebooks.</p>
