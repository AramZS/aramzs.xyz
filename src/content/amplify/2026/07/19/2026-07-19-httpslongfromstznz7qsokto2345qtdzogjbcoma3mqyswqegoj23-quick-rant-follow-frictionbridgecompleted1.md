<p>#atdev : So I'm making an offprint component so people can follow me on semble, grain, currents, etc. BUT WHY?!?! Didn't we hype up shared social graph? Why are we replicating old friction?</p>
<p>I've heard the arguments for and against app.bsky.graph.follow use and that is not the point of this longform post.</p>
<ol start="1"><li><p>1st login experience: let people know if you are using app.bsky.graph.follow, if you are, then no more steps are required</p></li><li><p>if you are using another schema: Immediately state follows are different here than Bluesky (yes Bluesky) "would you like to sync your follows?"</p></li><li><p>if yes: provide a selection screen + follow them all button!</p></li><li><p>offer ongoing sync, Add a keep follows in sync option in settings that users can run anytime. If you AREN'T going to build them an on going automated sync, build an <a href="https://aturi.to/did:plc:7qktq2csymlprtxrkgdchy3s">@airglow.run</a> automation and point them to it.</p></li></ol>
<p>if you are serious about your at://app then you need to steal or remix this UX idea so we don't have Dead Apps</p>
<p>I'm sorry if this is a bit ranty for a sunday, but when an alpha tester like me realizes this is a problem it's already much larger!</p>
