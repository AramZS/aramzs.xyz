<p>It's easy to start: Just download the ISO image and install Proxmox VE on your hardware. In five minutes you'll be creating your first virtual machines and containers.</p>
<p>The source code of Proxmox VE is licensed under the GNU AGPLv3 and free to download and use. With the bare-metal installation, you'll get a complete operating system based on Debian GNU/Linux, 64-bit, a Proxmox VE kernel with KVM and container support, great tools for backup/restore and HA clustering, and much more... Configuration is done easily with the intuitive web-based interface.</p>
<p>Ready to go? Take a look at the <a href="https://www.proxmox.com/en/products/proxmox-virtual-environment/requirements">system requirements</a>, then follow the steps below or <a href="https://pve.proxmox.com/pve-docs/chapter-pve-installation.html">read the full installation guide</a> in the Proxmox VE documentation.</p>
<p>Want to migrate to Proxmox VE? Learn how to migrate your existing VMs with the transition methods described in this guide: <a href="https://pve.proxmox.com/wiki/Migrate_to_Proxmox_VE">Migrate to Proxmox VE</a></p>
<h2>Fast and easy to install</h2>
<h3>Download ISO image</h3>
<p>The ISO image file is an image of a disk. Download the Proxmox VE ISO, then copy it to a USB flash drive or CD/DVD in order to use it.</p>
<p><a href="https://www.proxmox.com/en/downloads/proxmox-virtual-environment/iso">Download ISO image</a></p>
<h3>Boot from USB or CD/DVD</h3>
<p>Press 'Enter' to start the installation wizard on your dedicated hardware.</p>
<p>If you need help with the installation, read the documentation or get a subscription for technical support.</p>
<p><a href="https://www.proxmox.com/en/proxmox-virtual-environment/pricing">Need technical support?</a></p>
<h3>Configure the host machine</h3>
<p>You can configure the host easily via the web browser. No need to install a separate management tool.</p>
<p>Find all details in the documentation:</p>
<p><a href="https://pve.proxmox.com/pve-docs/chapter-sysadmin.html">How to configure</a></p>
<p>Note: Proxmox VE is a bare-metal installer, please be aware that the complete server is used and existing data on the selected disks will be removed.</p>
